# Enhanced 3x3 Design
These changes sought to improve the original 3x3 design to reduce plastic use, reduce overall shifting of the parts. This design also allows for the reduction of fans.
## Main Changes
1. Reduced plastic usage.
  * Removed lip sides of box, filter instead rests on ledge around outer walls.
  * Modified mounting brackets to be lower and smaller
2. Improve bonding. Use two attachment points on edges to prevent rotation of box components.
3. Integrate power port. Can cut a specified diameter on the handle center for a power port.
4. Deboss components and orientation for clarity
5. Fan Cutout is controllable in Fan Container to allow for 5x140 fan designs instead of 9x140 fan designs.
